# ศัพท์ที่ต้องรู้ (อธิบายง่าย ๆ)

| ศัพท์ | แปลว่า | เปรียบเทียบง่าย ๆ |
|---|---|---|
| **ADC** | ตัวแปลงสัญญาณจริง (แอนะล็อก) เป็นตัวเลข | เหมือนเอาไม้บรรทัดวัดความสูงแล้วจดเป็นตัวเลข |
| **DAC** | ตัวแปลงตัวเลขกลับเป็นสัญญาณจริง | เหมือนอ่านตัวเลขแล้วเปล่งเสียงออกลำโพง (ตรงข้าม ADC) |
| **Sampling (สุ่ม)** | ดูค่าสัญญาณเป็นช่วง ๆ | เหมือนถ่ายภาพทีละเฟรมจากวิดีโอ |
| **Sampling rate (อัตราสุ่ม)** | สุ่มกี่ครั้งต่อวินาที | ยิ่งถี่ ยิ่งละเอียด |
| **Quantization (ปัด)** | ปัดค่าให้เป็นขั้นที่ใกล้ที่สุด | เหมือนปัดเศษ 79.9 เป็น 80 |
| **บิต (bit)** | ความละเอียดของ ADC | 10 บิต = แบ่งได้ 1,024 ระดับ |
| **Nyquist** | กฎ: ต้องสุ่ม "มากกว่า 2 เท่า" ของความถี่สูงสุด | สัญญาณ 1 kHz ต้องสุ่มเกิน 2 kHz |
| **Aliasing** | สัญญาณเพี้ยนเพราะสุ่มไม่ถี่พอ | เหมือนล้อรถในหนังที่ดูหมุนย้อนกลับ |
| **ฟิลเตอร์** | ตัวกรองตัดความถี่สูงเกินทิ้ง | วางไว้ก่อนเข้า ADC เพื่อกันเสียงเพี้ยน |

## คำถามที่อาจโดนถาม
- **ยกตัวอย่างการใช้ ADC?** วัดอุณหภูมิ (LM35), ความชื้นดิน, ความสว่าง (LDR)
- **LM35 วัดได้ 0.25 V กี่องศา?** 25 °C เพราะ LM35 ให้ 10 mV ต่อ 1 °C
- **DHT11 ต้องใช้ ADC ไหม?** ไม่ต้อง มันส่งค่าเป็นดิจิทัลมาให้แล้ว
- **ต่อมอเตอร์เข้าขา DAC ตรง ๆ ได้ไหม?** ไม่ได้ กระแสไม่พอ ต้องมีวงจรขับ (motor driver)
- **DAC กับ PWM ต่างกันยังไง?** DAC ปล่อยแรงดันตามค่าจริง ๆ ส่วน PWM เปิดปิดเร็ว ๆ แล้วค่าเฉลี่ยเปลี่ยนตามสัดส่วนเวลาที่เปิด

## 3 อย่างที่ต้องจำ
1. สุ่มให้เร็วกว่า **2 เท่า** ของความถี่สูงสุด
2. จำนวนระดับ = **2 ยกกำลังจำนวนบิต** (10 บิต → 1,024)
3. บิตมาก = ละเอียดขึ้น

## ประโยคอังกฤษที่ใช้ได้ตอนพรีเซนต์
- "Analog signal is continuous." — สัญญาณแอนะล็อกต่อเนื่อง
- "Sampling rate must be more than twice the highest frequency." — ต้องสุ่มเกิน 2 เท่าของความถี่สูงสุด
- "More bits means higher resolution." — บิตมาก ละเอียดขึ้น
- "Thank you for listening." — ขอบคุณที่รับฟัง
