# Embedded System — ADC/DAC Presentation

งานพรีเซนต์วิชา Embedded System / AIoT หัวข้อ **การแปลงสัญญาณแอนะล็อกและดิจิทัล (ADC/DAC)** ทำเป็นคู่

**เปิดบนเว็บ:** https://omesct.github.io/embedded-system-adc-dac/

## ไฟล์สำคัญ
| ไฟล์ | คืออะไร |
|---|---|
| `adc-dac-presentation.html` | เดคปัจจุบัน 8 สไลด์ (ไฟล์ HTML เดียว เปิดในเบราว์เซอร์ได้เลย กด `R` เพื่อเปิดแผงอ้างอิง กดการ์ดหรือ "อ่านเพิ่ม" เพื่อดูเนื้อหาด้านใน) |
| `adc-dac-presentation-v1.html` | เวอร์ชันเก่า 20 สไลด์ (ดีไซน์เก่า เก็บไว้เทียบ) |
| `HANDOFF.md` | **แหล่งความจริงของทีม** — กติกา, บันทึกส่งต่อ, การตัดสินใจ อ่านก่อนเริ่มงานทุกครั้ง |
| `TASKS.md` | ใครรับงานอะไร สถานะเป็นอย่างไร |
| `docs/glossary.md` | ศัพท์ EN-TH สำหรับซ้อมพูด |

## เริ่มงาน
1. `git pull`
2. อ่าน `HANDOFF.md` และ `TASKS.md`
3. ทำงานเฉพาะส่วนที่ตัวเองรับ แล้ว commit/push
4. ก่อนหยุดงาน เขียน handoff ลง `HANDOFF.md` (3 บรรทัด: ทำเสร็จ / ค้าง / ต้องการอะไรจากอีกคน)
